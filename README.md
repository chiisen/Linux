## 請說明 Linux 運行級別（Runlevel）0~6 的意義

- 0：關機模式（系統關機）
- 1：單用戶模式（通常用於維護，只有 root 可登入）
- 2：無網路支持的多用戶模式
- 3：有網路支持的多用戶模式（常見於伺服器環境）
- 4：保留，未使用
- 5：有網路支持且啟用 X Window（圖形介面，多用於桌面環境）
- 6：重新啟動（重開機）

## 請列舉並簡述五個常用的 Linux 指令及其用途

- cp：複製檔案或目錄
- mv：移動檔案或目錄，或重新命名
- mkdir：建立新目錄
- ls：列出目錄內容
- rm：刪除檔案或目錄

## 請給出正確的關機與重新啟動伺服器的命令

- 關機命令：  
  `shutdown -h now`  或  `poweroff`
- 重新啟動命令：  
  `shutdown -r now`  或  `reboot`

**在 Linux 環境下，怎麼查執行中的處理程序？怎麼刪除？怎麼查找 PID=1688 的所有 log？**

---

### 1. 查詢執行中的處理程序

常用指令如下：

- `ps aux`：列出所有執行中的進程（處理程序）  
- `top` 或 `htop`：動態顯示系統目前執行中的進程狀態  
- `ps -ef`：以全格式顯示所有進程  
- `ps aux | grep 程式名稱`：查詢特定程式的進程

---

### 2. 刪除執行中的處理程序

- `kill `：發送終止訊號給指定 PID 的進程
- `kill -9 `：強制終止指定 PID 的進程（SIGKILL）
- `killall `：根據程式名稱終止所有相關進程

---

### 3. 查找 PID=1688 的所有 log

這部分要看 log 的實際存放位置與格式，通常有以下幾種做法：

- 如果 log 在 `/var/log/` 目錄下，可以用 `grep` 查詢相關資訊，例如：
  ```bash
  grep 1688 /var/log/*  # 查找所有包含 1688 的 log 行
  ```
- 若 log 有記錄 PID 欄位，可用：
  ```bash
  grep "1688" /path/to/logfile
  ```
- 也可以用 `journalctl` 查詢 systemd 管理的服務 log：
  ```bash
  journalctl _PID=1688
  ```

---

### 總結表

| 需求                | 指令範例                                |
|---------------------|-----------------------------------------|
| 查執行中程序        | `ps aux`、`top`、`htop`                 |
| 查特定程序          | `ps aux | grep 程式名稱`                |
| 刪除程序            | `kill `、`kill -9 `           |
| 刪除特定名稱程序    | `killall `                    |
| 查 PID=1688 的 log  | `grep 1688 /var/log/*` 或 `journalctl _PID=1688` |

---

如需更詳細 log 查詢方法，請依實際 log 檔案路徑與格式調整 grep 指令。
